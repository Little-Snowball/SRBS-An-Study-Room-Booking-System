# 测试场景目录（T01—T50）

来源：《完整开发实施手册》16.2 用例目录。分层：纯单测（unit）、MySQL 集成测试（integration，studyroom_test）、
安全测试（security）、并发测试（concurrency）。并发测试用 barrier 同时放行两个独立请求，每请求独立事务与连接；
不得用 `@Transactional` 测试方法包住全部线程。

## 数据库一致性证据 SQL（16.3，每次并发测试后执行，期望 0 行）

```sql
-- 同座位有效预约重叠
SELECT a.id, b.id FROM reservation a JOIN reservation b
  ON a.seat_id = b.seat_id AND a.id < b.id
  AND a.start_at < b.end_at AND a.end_at > b.start_at
WHERE a.status IN ('RESERVED','IN_USE','LEFT_TEMP')
  AND b.status IN ('RESERVED','IN_USE','LEFT_TEMP');
-- 同学生重叠：把 seat_id 换成 user_id 再执行一次
-- 信用越界 / 流水不连续 / 事件键重复 / 同订单多处罚：期望均 0 行
```
